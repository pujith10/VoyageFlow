# ✈️ VoyageFlow – Travel Experience Simulator  
A fully responsive, multi-page travel simulation website built using **HTML, CSS, and Vanilla JavaScript**. VoyageFlow guides a user through a complete travel journey — from registration to reading travel blogs, planning a trip, calculating prices, and viewing the final confirmation page — all without any backend.

## 🎯 Project Overview  
VoyageFlow is designed as a **front-end only** project for learning, portfolio building, and academic submissions.  
It simulates a real travel portal with:

- 📝 **Registration Form** (with validation)  
- 🌍 **Travel Blog** showcasing multiple destinations  
- 🧮 **Trip Planner & Price Calculator**  
- 🛒 **Real-Time Cart System**  
- 🎉 **Thank You / Confirmation Page**  
- ℹ️ **About Us Page**

Built with **no backend, no frameworks, and no database** — just clean, structured, modern JavaScript.

---

## 🚀 Features

### 🔹 **Page 1 – Registration**
- Validates:
  - Phone Number (10 digits)  
  - PIN Code (6 digits)  
  - Email Format  
- Custom success modal (no alert/confirm prompts)  
- Redirects to travel blog page  

### 🔹 **Page 2 – Travel Blog**
- 5+ detailed, scrollable destination sections  
- Sticky navbar with smooth scrolling  
- Informative and visually appealing content  

### 🔹 **Page 3 – Trip Planner + Cart**
- Select:
  - Travel options  
  - Stay plans  
  - Food packages  
  - Activities  
- All selections update total **in real time**  
- Slide-in **cart drawer** + floating mobile button  
- Remove items from cart anytime  
- Fully dynamic state management using JavaScript  

### 🔹 **Page 4 – Confirmation**
- Stylish "Thank You" page  
- Explains the entire flow  
- Provides next options & learning suggestions  

### 🔹 **About Page**
- Overview of:
  - Vision  
  - Mission  
  - Project purpose  
  - Technical highlights  
- Timeline of how the website works
