How to Use This Project

This website is ideal as a front-end assignment or portfolio project. It demonstrates:

  • ✔ Form validation and custom modals.
  • ✔ Single-page style scrolling between sections.
  • ✔ State handling using JavaScript objects (for the cart).
  • ✔ Responsive, mobile-first layout.

You can extend this further by connecting it to a backend or adding real APIs in future versions.
